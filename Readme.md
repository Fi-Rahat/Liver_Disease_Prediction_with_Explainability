# Liver Disease Prediction Using Machine Learning

## Overview

This project explores the use of machine learning algorithms for liver disease prediction using structured patient data. It includes data preprocessing, feature selection, model training, performance evaluation, and explainable AI techniques.

The project was developed as part of my learning and practical work in machine learning.

## Objectives

- Explore and preprocess the dataset.
- Handle missing values and class imbalance.
- Apply feature selection techniques.
- Train and compare multiple machine learning classifiers.
- Evaluate model performance using classification metrics.
- Explore model interpretability using SHAP.

## Methodology

The notebook covers the following stages:

1. Data loading and exploratory analysis
2. Data preprocessing
3. Handling class imbalance using SMOTE
4. Feature selection
5. Training and comparing machine learning models
6. Model evaluation and visualization
7. Explainability analysis using SHAP

## Models and Techniques

The notebook explores multiple classification algorithms, along with feature selection, hyperparameter tuning, ensemble methods, and model evaluation.
